# Painel Nativo vs. Docker

Interface web local em Django (sem banco de dados) para visualização interativa dos micro-benchmarks.

## Como rodar

1. Ative o ambiente virtual:
```bash
python -m venv venv
source venv/bin/activate
```

2. Inicie o servidor:
```bash
python manage.py runserver
```

3. Acesse no navegador:
http://127.0.0.1:8000/
